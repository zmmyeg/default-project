# Default Project

My OpenCode workspace on Windows.

## What's here

- `.opencode/` — OpenCode plugins and skills for this project
  - `plugins/replicate.ts` — Replicate API tools (image/video generation)
  - `skills/replicate/` — instructions for using those tools

## Setup notes

The Replicate API token is stored in the user config folder, not this
repository:

    ~/.config/opencode/replicate-token.txt

## Version control

This folder is tracked with Git. Commits record every change, so any
mistake can be inspected and undone.

## About

Created while working through the OpenCode School lessons.
